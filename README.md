# Python Security Tools

A collection of Python scripts I have built to automate basic security tasks.

##  Tools
- **Header Checker:** Checks HTTP response headers for security misconfigurations.
- **Directory Brute-forcer:** A basic script to brute-force directories on a web server.
- **Hash Cracker:** A simple dictionary attack script for MD5/SHA1 hashes.

##  How to use
Ensure you have Python 3 installed. Run any script using:
`python3 script_name.py -h`
